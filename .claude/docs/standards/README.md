# Standards do projeto

Cada arquivo aqui detalha uma convenção que o CLAUDE.md só resume. **Standards são derivados
por projeto, nunca copiados prontos de outro** — o método vem das skills, o conteúdo vem do
contexto deste projeto.

Cobertura atual:

| Arquivo | Conteúdo |
|---|---|
| `design_system.md` | marca, tokens, composição, superfícies, motion e acessibilidade |
| `frontend.md` | arquitetura, CSS, estado e protocolo de migração página a página |
| `testing.md` | configuração da suíte e achados que só a verificação real revelou |

Regra de altitude: CLAUDE.md aponta, standard detalha, código obedece.
